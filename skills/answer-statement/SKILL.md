# 答辩状 / 答辩意见 起草规范（××××公司 · 被诉案件）

本 skill 的格式来源：对 `D:\【×××】\【诉讼】\【被诉案件】` 下 **78 份答辩类文书（40 份 .docx、36 份 .pdf、2 份 .doc）** 逐份解析首部字段、标题层级、落款与字体后聚合而成（2026-09-10）。
统计结论（.docx 样本 40 份）：
- `答辩人` 出现 39/40（必备）；`法定代表人` 33、`被答辩人` 32、`事实与理由` 23、`答辩请求` 22、`住址` 21、`案号` 18、`身份证` 14、`统一社会信用代码` 13。
- 标题（首段）：`民事答辩状` 最常见，其次 `答辩状`，另有 `二审答辩状`、`补充答辩意见`。
- 正文一级标题数量：2–5 个最常见（12 份为 2 个、5 份为 3 个、5 份为 4 个）。
- 落款固定为：`综上…` → `此致` → 受诉法院/仲裁机构 → `答辩人：×××` → `委托代理人：______` → 日期。

## 何时使用

起草或复核以下文书时**必须**先读本 skill：民事答辩状、答辩状、答辩意见、二审答辩状、补充答辩（意见）、增加答辩、管辖异议答辩、劳动人事争议仲裁答辩意见。

## 硬性起草流程

1. **先定案由，再定框架**：读**开庭传票/应诉通知书的「案由」栏**（最权威定性依据）。案由决定请求权基础（如「请求撤销个别清偿行为纠纷」→《企业破产法》第 32/40 条 +《破产法解释（二）》第 44 条；「劳动争议」→ 劳动关系/用工主体责任；「买卖合同纠纷」→ 合同相对性）。
2. **读被答辩人的诉请与证据**：起诉状（诉请逐项拆解 + 请求权基础）＋ 证据清单（逐项对应质证意见）＋ 合同/裁判文书原件。**诉请与证据要一一对应**，找出「原告主张 ≠ 其证据」之处。
3. **提取本方抗辩素材**：本项目合同（分包/买卖/租赁/劳务）、结算与付款凭证、生效裁判、授权文件、工伤保险参保记录、财务独立（与××股份/分公司）证据。
4. **按「程序抗辩优先、实体抗辩次之」排布**（见下「论证框架」）。
5. **套用文书骨架**（见 `references/首部与落款规范.md`）。
6. **排版（强制）**：一律套用 `C:\Users\ACME\.workbuddy\skills\docx\references\诉讼文书格式规范.md`（2026-09-11 依用户真实卷宗 `0409【×××】`／`0414【×××】` 解析）。用户明确要求：**「我说写答辩状、起诉状要和我的格式完全一致；我说写证据清单、质证意见也要与我的格式一致」**。要点：
   - 文书名 → Word 内置**标题 1**（方正小标宋简体 22pt 加粗居中）；
   - **案号行右对齐**（首行缩进 2 字符）；
   - **答辩人／被答辩人／答辩请求／事实与理由 → 标题 2**（黑体 15pt 加粗，段前段后 156）；
   - **一、二、… → 标题 3**（楷体）；**（一）／1. → 标题 4**（仿宋_GB2312）；**均保留首行缩进 2 字符，不得顶格**；
   - 正文：仿宋_GB2312 15pt／Times New Roman、两端对齐、首行缩进 2 字符、段前段后 156、固定行距 22 磅；
   - 「此致」在正文段；**受文法院名顶格**；**落款（答辩人／委托代理人／日期）右对齐**；
   - 页边距左右 1800 twips（3.175cm）；页脚居中 PAGE 域。
   **注意**：答辩状**不套用**培训/课程类文档的排版，首部字段行不用「正文缩进即可」的随意处理。
7. **命名与存放**：`{文书类型}【相对方简称】项目简称案号.docx`，直接存入该案文件夹（与卷内既有材料命名一致）。例：`答辩状【×××】中集数科（20XX）Xxxxx民初XXXX号.docx`。

## 论证框架

**第一层：程序抗辩（优先，能一击致命先写）**
- 主体不适格 / 非适格被告（合同相对性、非合同相对方、非用人单位）；
- 管辖异议（违约之诉 vs 侵权之诉、主要办事机构所在地、协议管辖、专属管辖）；
- 请求权基础错误（案由与诉请形式不匹配、以 A 制度套 B 事实）；
- 诉讼请求不明确、无明确诉讼标的、缺乏事实基础（《民事诉讼法》第 122 条）；
- 起诉期限/除斥期间/法定不变期间（如破产抵销无效须"受理之日起 3 个月"内起诉）；
- 未经前置程序（劳动争议仲裁前置）、重复起诉、仲裁协议。

**第二层：实体抗辩**
- 合同关系与合同相对性（我方非合同主体、无付款义务）；
- 付款条件未成就（结算未完成、发票未足额、质保期未满、验收未完成）；
- 已足额付款（附付款凭证/扣减明细）；
- 金额与利息（利息起算点、标准、基数；无约定则按 LPR 主张调减）；
- 主体责任划分（甲指分包、劳务派遣、专业分包、总包已尽审查/参保义务）；
- 法人独立（××××公司与××股份、分公司与总公司财务独立，不承担连带责任）；
- 违约金/律师费/保全费等无合同依据；
- 诉讼费由原告承担。
- **每种抗辩必须"事实 + 证据 + 法条/司法解释/判例"三段闭环**，先写结论标题、再展开论证。

**第三层：兜底段（"综上"）**：收束为「原告诉请缺乏事实与法律依据 → 恳请驳回 → 维护答辩人合法权益」。

## 引注核验

- 引注（法条/司法解释/判例）**必须先核对官方原文**再写入文书：用 `npc-law-db` skill 逐条取《中华人民共和国企业破产法》《民法典》《民事诉讼法》及最高院司法解释的**条文原文**（`scripts/article.py {条号} {法律名或bbbs}`），不得凭记忆书写条号。
- `legal-citation-comprehensive` skill 为**本地已可用**状态（2026-09-11 改造：《法学引注手册》**2019年11月版，规则1—100**；audit 0 错误、self_test 全过）。核验用法：`python scripts/citation_diagnose.py --text "<引注>"` 查类型/缺项/建议格式，`python scripts/handbook_lookup.py --rule <条号>` 查规则正文。
- **诉讼文书的引注形式应遵循该手册（2019年版）**，要点：
  - **规则 61（条款序数）**：行文援引用**阿拉伯数字并省略序数括号**——《民法典》第568条第1款、第40条第2项；**原文引用**条文/司法解释处**从原文**（条、款用汉字，项用汉字加括号），故引号内的条号保留汉字（如"属于企业破产法第四十条第（二）、（三）项规定的情形之一"）；**改引号内文字即属引用失真，严禁**。
  - **规则 64（规范性文件）**：司法解释**应当标明制定机关与文件号**（六角括号〔〕），如「《最高人民法院关于适用〈中华人民共和国企业破产法〉若干问题的规定（二）》（法释〔2020〕18号）第44条」。
  - **规则 59（名称缩写）**：省略「中华人民共和国」无需说明；自定义缩写须在**首次出现处**说明「以下简称《破产法解释（二）》」。
  - **规则 70/71（司法案例）**：案例名称「×××诉×××（案由）案」＋审判法院**全名**＋（年份）案号＋文书类型；当事人多人的可"等"概括。例：`四川元丰化工股份有限公司管理人诉德阳市川丰化工有限公司请求撤销个别清偿行为纠纷案，最高人民法院（20XX）最高法民申XXXX号民事裁定书`。
- 诉讼文书（答辩状/答辩意见）**不用脚注**，法条随文标注即可。
