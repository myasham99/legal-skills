## 二、首部字段（按出现频次排列的推荐顺序）

```
案号：（20XX）Xxxxx民初XXXX号          ← 18/40；建议始终填写
答辩人：××××工程局有限公司         ← 39/40，必备
住址：广州市天河区科韵路16号自编B栋5楼     ← 21/40（亦作「住所」「住所地」「地址」）
法定代表人：×××，职务：董事长            ← 33/40（亦作「×××，董事长」）
被答辩人：×××                          ← 32/40
住址：×××                              ← 被答辩人为自然人时
身份证号：×××                          ← 14/40，被答辩人为自然人时必填
法定代表人：×××                        ← 被答辩人为单位时
统一社会信用代码：×××                   ← 13/40，单位主体
答辩请求：
事实与理由：
```

**四种常见组合（照抄即可）**

1. 标准式（用户模板，最稳）：
   `案号 → 答辩人 → 住址 → 法定代表人 → 被答辩人 → 住址 → 身份证号 → 答辩请求 → 事实与理由`
2. 完整主体式：
   `案号 → 答辩人 → 住址 → 法定代表人 → 被答辩人 → 住所地 → 法定代表人 → 答辩请求 → 事实与理由`
3. 直接式（无案号）：
   `答辩人 → 住址 → 法定代表人 → 被答辩人 → 答辩请求 → 事实与理由`
4. 仲裁简式：
   `答辩人 → 统一社会信用代码 → 法定代表人 → 被答辩人 → 住址 → 身份证号`

**主体称谓变体**：以「答辩人 / 被答辩人」为主；当本方为**第三人**或**多被告**案件时，部分文书改用诉讼地位称谓（`原告 / 被告一 / 被告二 / 被告三 / 第三人 / 申请人 / 被申请人`），如「答辩意见【×××】华大基因（20XX）Xxxxx民初XXXX号」用"被告三"。

**主体名称必须照抄当期工商登记**：
- ××××工程局有限公司 —— 法定代表人 **×××**（住所：××××）
- ××××有限公司 —— 法定代表人 **×××**（住所：××××）
- ××××有限公司珠海分公司 —— 负责人 **孙国华**
- ××××股份有限公司（涉股份时需另行办理股份用印/授权）
- ⚠️ 旧文书中的「×××」为前任法定代表人，**不得沿用**。

## 三、答辩请求的三种写法

| 写法 | 示例 | 适用 |
|---|---|---|
| A. 单句（推荐） | `答辩请求：` 换行 `依法驳回被答辩人的全部诉讼请求；本案诉讼费用由被答辩人承担。` | 一般案件 |
| B. 分项 | `答辩请求：` 换行 `1. 依法驳回被答辩人的诉讼请求；` `2. 本案诉讼费用由被答辩人承担。` | 诉请多项、需逐项对应 |
| C. 编号式 | `一、答辩请求` / `二、答辩理由`（或 `一、答辩意见` / `二、事实与理由`） | 仲裁案件、简式文书 |

## 四、正文与落款

- 正文一级标题：手打「一、二、三…」，**先结论后展开**（标题写成一句完整主张，如"一、××××公司与被答辩人不存在劳动关系，不应承担工伤保险责任"）。
- 层级：`一、` → `（一）` → `1、`；不用自动编号。
- 收束段：以「综上，……」开头，收束为"诉请缺乏事实与法律依据 → 恳请贵院/贵庭查明事实，依法驳回…… → 以维护答辩人的合法权益"。
- **落款（固定结构，勿缺）**：

```
此致
××人民法院（或：××仲裁委员会 / ××劳动人事争议仲裁院××仲裁庭）
答辩人：××××工程局有限公司
委托代理人：______________________
二〇二六年　　月　　日
```

  变体：代理人称谓可用 `委托代理人 / 诉讼代理人 / 代理人 / 委托诉讼代理人`；日期可用阿拉伯数字（`2025年8月7日`）或汉字（`二〇二五年十二月十六日`）或留空（`年　月　日`）；部分文书把「答辩人」后的冒号省略（`答辩人 ××××工程局有限公司`）。
- **撤回/放弃的情形**：若本方为第三人或仅需表明立场，仍须保留「答辩人 + 委托代理人 + 日期」。
