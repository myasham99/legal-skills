# 债务计算表生成器（debt_calc）

本技能封装 `debt_calc.py`——一套从**判决书/裁定书**中提取债务要素，按法定规则计算利息，并生成"××××公司 债务计算表"格式公式联动 Excel 的完整工作流工具（v5.0）。

## 何时使用

- 用户给出判决书（PDF/扫描件/txt），要求"算债务 / 算利息 / 算欠付总额 / 生成债务计算表"。
- 用户提到本金、普通利息、加倍迟延利息、LPR、履约保证金、受理费、保全费等债务要素。
- 需要把判决书信息整理成标准债务计算 Excel 并归档到 `D:/【用户名】/【诉讼】/【执行履行】/债务计算`。

## 核心工作流程（process_debt_calc，4 步）

1. **OCR 识别**：优先 `ocr.extract_text`，失败降级 `fitz` 文字层 / 同名 txt；主文件 + 依据文件文本合并。
2. **信息提取与确认**：自动提取案号、对方当事人、项目、本金、履约保证金、受理费、保全费、利息起算日、判决作出日、利息总额上限、审级，交互确认并推算**加倍迟延起算日**。
3. **生成 Excel**：`generate_debt_excel()` 输出公式联动版 `.xlsx`。
4. **归档**：调用 `naming_n_filing` 生成标准文件夹名（`债务计算【{相对方}】{项目}{案号}`），在 `D:/【用户名】/【诉讼】/【执行履行】/债务计算` 下建文件夹，复制 Excel 与依据文件（依据文件保持原名）。
   - **案号规则（2026-09-14 用户确认，强制）**：归档文件夹名、xlsx 文件名后缀、**以及表内"案号"栏**一律用**一审案号**（如 `（20XX）Xxxxx民初XXXX号`），二审/终审案件也用其一审案号——便于一眼识别执行法院；依据文件（判决书等）保持其原有文件名不变。
   - 例：`债务计算【×××】保利国际广场二期（20XX）Xxxxx民初XXXX号\债务计算【×××】保利国际广场二期（20XX）Xxxxx民初XXXX号.xlsx`（内含二审判决 PDF 与一审判决 PDF，均原名）。

## 计算规则（速览）

| 项 | 规则 |
| --- | --- |
| 利率 | 1 年期 LPR，按公布日（每月 20 日）自动分段；2025-05-20 至今固定 3.00% |
| 普通利息 | `本金 × 年利率 / 360 × 天数` |
| 加倍迟延利息 | `基数 × 1.75/10000 × 天数`（日利率，不除 360）；**基数 = 原本之债（本金），诉讼费用一概不计**（见下节） |
| 冲抵顺序 | 付款先冲利息，余下冲本金；利息不足时滚存、本金不变 |
| 履约保证金 | 不计普通利息，但计入加倍迟延基数 |
| 生效期限 | 一审 15 日上诉期；二审/终审送达即生效（0 日）；履行期限以判决主文为准（常见 5 日/10 日） |
| 加倍迟延起算日 | **履行期间届满之日 + 1 日（届满次日为迟延第 1 天）**；即 `收到判决日 + 生效期限 + 履行期限 + 1` |

## ★ 加倍迟延利息 · 基数与起算（2026-09-14 依权威口径修正，强制）

> 此前按"法条字面届满之日"起算、并把受理费/保全费并入基数的做法**已废止**。

1. **基数 = 原本之债（本金）**。依《最高人民法院关于执行程序中计算迟延履行期间的债务利息适用法律若干问题的解释》（法释〔2014〕8号）第1条，"除一般债务利息之外的金钱债务"；**最高人民法院执行局《该解释理解与适用》明确：该金钱债务指"原本之债"即本金，除此之外的诉讼费、鉴定费、拍卖费等一概不予计算**。
   - 不计入：**案件受理费、申请保全费、执行费**等诉讼费用（收款人是法院、非当事人之间的金钱债务；最高人民法院执行局口径 + 厦门中院、江西共青城法院、连云港海州法院等一致）。即使主文写"由被告负担并向原告迳付"，多数法院仍持保守口径剔除；如需主张，应单独列项并请执行法官核定。
   - 可计入：判决主文明确判付的**金钱债务本金**，以及作为金钱给付判项的**违约金、损害赔偿性固定金额、判付给对方的律师费**等（一般债务利息本身不计）。
2. **起算日 = 履行期间届满之日的次日**。法释8号第2条"自履行期间届满之日起计算"，因期间届满之日不计入本日（民事诉讼法期间计算规则），实务统一以**届满次日的第 1 天**起算（江西省高级人民法院释义；最高人民法院破产债权审查意见亦"自次日起算"）。
   - 例：二审 7-24 送达（即生效）→ 履行期 10 日（7/25~8/3）→ 届满日 8/3 → **加倍自 8/4 起算**。
3. **截止日**：法释8号第3条——计算至**被执行人履行完毕之日**（末日计入）；分次履行的，相应部分算至每次履行完毕之日；法院划拨/提取之日至划拨、提取之日；拍卖、变卖、以物抵债的算至成交/抵债裁定生效之日。
4. **负担与清偿顺序**：加倍部分债务利息最后清偿（法释8号第4条）；金钱债务内部按《民法典》第561条：费用→一般利息→主债务。

**权威来源**：flk.npc.gov.cn（法释〔2014〕8号全文）；最高人民法院执行局《关于执行程序中计算迟延履行期间的债务利息司法解释理解与适用》；江西省高级人民法院《浅谈关于执行程序中迟延履行利息的理解与适用》（jxgy.jxfy.gov.cn）；厦门市中级人民法院、连云港市海州区人民法院等案例分析。

完整 LPR 历史表（70 条）与利息分段算法详见 `references/calculation_rules.md`。

## 输出格式规范（2026-09-11／09-14 用户确认，强制）

- **案涉项目用全称**：`generate_debt_excel()` 内置 `to_full_project_name()`，查 `naming-n-filing/references/project_mapping.md`（简称→全称）自动转换（如 岭山林语→东莞保利岭山林语花园项目），查不到原样返回；归档文件夹命名仍用简称。
- **字体统一**：汉字单元格 = 宋体、数字/西文单元格 = Times New Roman；标题 28pt、正文 20pt。
- **对齐**：全表一律居中（含金额与文本值）。
- **数字格式**：只有金额用千位分隔 `#,##0.00;(#,##0.00);"-"`，利率 `0.00%`。
- **行高不写死**：不设置 row height，单元格 `wrap_text=True`，行高由 Excel/WPS 自适应，保证每行文字完整呈现。
- **列宽统一为 30**：A~G 七列列宽一律 30（2026-09-14 用户确认）。
- **无则省（2026-09-14）**：判项中没有的项目一律不写入表格——履约保证金、保全费、执行费等金额为 0/无的项，基本信息区、加倍迟延详单与汇总区都不出现该行。
- **加倍详单"计息时间"只写起止（2026-09-14）**：B 列固定为 `计息{起算日}~{截止日}`，**不写基数构成等说明文字**（基数构成体现在"基数构成/基数金额"列即可）。
- **计息区间用两列（2026-09-14）**：利息详单与加倍迟延详单均以**"起息日""截止日"两列**表示计息区间（真日期值 + 中文日期格式），**不再写"计息X~Y"文字**；天数列 = `截止日 − 起息日 + 1`（含头含尾）。
- **汇总区格式（2026-09-14）**：汇总每个项目单独占一行，**标签列 A:C 合并、数值列 D:G 合并**；行按实际存在的项目动态生成（本金 →〔履约保证金〕→ 利息 → 加倍迟延利息 → 各项费用 → 总计欠付），"总计欠付"= 各项目行之和（公式）。

## 执行费（2026-09-14 用户确认）

- **前置询问（强制）**：生成债务计算表前，须先问用户该案**是否已进入执行程序**；用户答"是"才计执行费，并由**用户提供执行标的金额**。
- **计费依据**：《诉讼费用交纳办法》（国务院令第481号）第14条第(一)项第2目——执行金额 ≤1万元每件 50 元；超过1万至50万部分 1.5%；超过50万至500万部分 1%；超过500万至1000万部分 0.5%；超过1000万部分 0.1%，分段累计。脚本函数 `calc_exec_fee(amount)` 直接调用（已随 skill 提供）。
- **负担方**：依同办法第38条，申请执行费**由被执行人负担**。
- **计入方式**：作为 `fee_items` 的一项（`{'name':'执行费','amount':calc_exec_fee(执行标的)}`），自动进入基本信息区与汇总表。

## 可选参数（直接调 `generate_debt_excel(params, path)` 时使用 · 2026-09-18 新增）

| 参数 | 默认 | 作用 |
| --- | --- | --- |
| `params['principal_items'][i]['label']` | 自动 `名称（计息）` | 自定义本金行标签，如 `货款本金（已付清·计息基数）` |
| `principal_settled` | `False` | `True` 时**汇总区不列"本金"行**（本金已清偿，仅余利息/费用） |
| `interest_label` | `'利息'` | 汇总区利息行的标签。调解书约定违约金时填 `'违约金'` |
| `include_double_delay` | `True` | `False` 时**完全不写**加倍迟延板块、基本信息"加倍迟延起算日"行、汇总"加倍迟延利息"行 |

> `generate_debt_excel()` 仍要求 `params['principal']`（数值），它是利息详单 C 列公式的唯一源头；
> `principal_items` 只负责基本信息区的**显示**。两者需保持一致。

### 场景：本金已付清、只剩违约金与费用（2026-09-18 新城石材案确立）
调解书约定"任何一期逾期即就未付货款计违约金、自某日起算"、而本金后续已清偿时：
1. `principal` / `principal_items[0].amount` 填**该笔逾期本金**（作计息基数）；
2. `principal_settled=True` → 汇总不出现本金；
3. `interest_label='违约金'`；
4. `include_double_delay=False`（调解书无加倍迟延条款，且本金已清）；
5. 贴息费/手续费等**未付费用**逐笔进 `fee_items`（如 `贴息费（第1笔）`…），汇总自动各占一行；
6. 调解书载明由**对方**负担的受理费/保全费**不得**计入我方债务。
- 实例：`债务计算【新城石材】中山翠亨（20XX）Xxxxx民初XXXX号`
  —— 基数 268,933.94，2025-03-31~2026-09-18 违约金 12,072.15 ＋ 4 笔贴息费 11,437.80 ＝ **总计欠付 23,509.95**。
