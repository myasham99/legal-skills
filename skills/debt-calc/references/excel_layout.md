# Excel 表结构与公式联动（excel_layout）

本文档是 `debt_calc.py` 中 `generate_debt_excel()` 生成表的结构与样式详解。

## 0. 输出格式规范（2026-09-11／09-14 用户确认，强制）

1. **案涉项目必须用项目全称**：生成时由 `to_full_project_name()` 查 `naming-n-filing/references/project_mapping.md`（简称→全称）自动转换（如 岭山林语→东莞保利岭山林语花园项目）；查不到时原样返回。归档文件夹命名仍用简称（保持既有惯例）。
2. **字体统一**：汉字单元格 = 宋体，数字/西文单元格 = Times New Roman；标题 28pt，正文 20pt，不加颜色。
3. **对齐**：全表一律居中（水平+垂直居中，含金额与文本值），不使用左/右对齐。
4. **数字格式**：只有金额单元格用千位分隔格式 `#,##0.00;(#,##0.00);"-")`；利率 `0.00%`。
5. **行高**：不写死（不设置 row height），所有单元格 `wrap_text=True`，行高由 Excel/WPS 按内容自适应，保证文字完整呈现。
6. **无则省（09-14）**：判项中没有的项目不写入表格——`deposit=0` 时加倍迟延详单与汇总区都不出现"履约保证金"行；金额为 0 的 `fee_items`（受理费/保全费/执行费等）一律不写入基本信息区与汇总区。
7. **汇总区格式（09-14）**：项目行按其存在情况**动态生成**（本金 →〔履约保证金〕→ 利息 → 加倍迟延利息 → 各费用项 → 总计欠付），每行**标签列 A:C 合并、数值列 D:G 合并**；"总计欠付" = 各项目行 D 列之和（公式）。
8. **执行费（09-14）**：生成前须询问是否已进入执行程序；确认后由用户提供执行标的，用 `calc_exec_fee(执行标的)`（《诉讼费用交纳办法》第14条第(一)项第2目分段累计）计算，作为 `fee_items` 一项计入；依同办法第38条由被执行人负担。
9. **加倍迟延基数与起算（09-14 依权威口径修正）**：**基数 = 原本之债（本金）**——诉讼费（受理费）、保全费、执行费、鉴定费等一概不计（最高人民法院执行局《理解与适用》），一般债务利息不计；**起算日 = 履行期间届满之日的次日**（届满之日不计入本日），截止日为履行完毕之日（末日计入）。加倍详单的"基数金额"列因此只引用本金行；B 列"计息时间"只写 `计息{起}~{止}`，**不写基数构成说明**。
10. **案号口径（09-14）**：文件夹名、xlsx 文件名后缀**及表内"案号"栏一律用一审案号**（二审/终审案件亦用其一审案号），便于一眼识别执行法院；依据文件（判决书等）保持原名。即 `params['case_no']` 直接传一审案号。

## 1. 总体设计（v5.0 公式联动）

**唯一数值源头 = 基本信息表**（第 5~10 行）。其余板块全部通过 Excel 公式引用，改基本信息即可联动重算：

```
基本信息（数值源头）→ 利息计算详单 → 加倍迟延详单 → 汇总 → 总计欠付
```

列布局：7 列，**列宽全部为 30**（A~G 均 30）。

## 2. 板块 0：标题

- 第 1 行，A1:G1 合并，内容"××××公司 债务计算表"，28 号宋体加粗（行高不写死，自适应），外框中粗边框。

## 3. 板块 1：基本信息（数值源头）

每行 A:C 合并放标签（20 号宋体加粗），D:G 合并放数值。行序：

1. 案号（字符串，居中）
2. 案涉项目（字符串）
3. 债权人（字符串）
4. `principal_items` 各项（数值，会计格式）—— 标签加"（计息）"或"（不计息）"后缀
5. `fee_items` 各项（数值）
6. 利息起算日（字符串）
7. 加倍迟延起算日（字符串）
8. 利息计算截止日（字符串）
9. 利息总额上限（数值，可选，仅当 `interest_cap` 非空）

关键行号通过 `get_row()` 按标签关键词定位，供后续公式引用：

| 行号变量 | 关键词 | 兜底偏移 |
| --- | --- | --- |
| `ROW_PRINCIPAL` | 本金（计息） | START+3 |
| `ROW_DEPOSIT` | 履约保证金 | START+4 |
| `ROW_ACCEPTANCE` | 受理费 | START+5 |
| `ROW_PRESERVATION` | 保全费 | START+6 |

## 4. 板块 2：利息计算详单

表头 7 列：`起息日 | 截止日 | 计息本金 | 天数 | 年利率 | 本段利息 | 挂账利息`（区间不再用"计息X~Y"文字）。

- 起息日/截止日 = **真日期值**（number_format `yyyy"年"mm"月"dd"日"`），便于天数相减。
- 起始行（利息起算行，浅灰底 `D9D9D9`）：A 填利息起算日，B 空，C = 本金公式，G = 0。
- 每个合并后的计息段一行：
  - C（计息本金）= `=D{ROW_PRINCIPAL}`（公式引用，付款减损后需手动改）
  - **D（天数）= `=B{行}-A{行}+1`**（含头含尾），E = 年利率（`0.00%` 格式）
  - **F = `=C{行}*D{行}*E{行}/360`**
  - **G = `={上一行G}+F{行}`**（挂账利息累计）

## 5. 板块 3：加倍迟延利息计算详单

表头 7 列：`基数构成 | 起息日 | 截止日 | 基数金额 | 天数 | 日利率 | 金额`。

- 本金行（有履约保证金时再加一行）：
  - B/C = 起算日 / 截止日（真日期值），D = `=D{ROW_PRINCIPAL}`（保证金行 `=D{ROW_DEPOSIT}`）
  - **E（天数）= `=C{行}-B{行}+1`**（含头含尾），F = 文本 `1.75/10000`
  - **G = `=D{行}*E{行}*1.75/10000`**（日利率，不除 360）
  - 起算日 > 截止日（尚未起算）时，B/C/E 留空、G 置 0
- **无履约保证金时不写该行**（2026-09-14 规则）。

## 6. 板块 4：汇总

每行：标签列 **A:C 合并**、数值列 **D:G 合并**（加粗）；项目行按其存在情况**动态生成**：

| 行（按存在情况） | 公式 |
| --- | --- |
| 本金 | `=D{ROW_PRINCIPAL}` |
| 履约保证金（有才列） | `=D{ROW_DEPOSIT}` |
| 利息 | `={last_g_ref}`（利息详单最后一行 G） |
| 加倍迟延利息 | `=G{ROW_DD_PRINCIPAL}[+G{ROW_DD_DEPOSIT}]` |
| 各 fee_items（受理费/保全费/执行费…） | `=D{基本信息对应行}` |
| **总计欠付** | `=D各项目行之和` |

v5.0 起不再有"待履行总计"行，总计欠付即为最后一行。

## 7. 样式规范

| 项 | 规范 |
| --- | --- |
| 中文字体 | 宋体 |
| 英文/数字字体 | Times New Roman |
| 标题字号 | 28 加粗（行高不写死，自适应） |
| 正文字号 | 20（行高不写死，自适应） |
| 边框 | 细线（thin），外框中粗（medium） |
| 事件行填充 | `D9D9D9` |
| 对齐 | **全部居中**（含金额与文本，wrap） |
| 会计格式 | `#,##0.00;(#,##0.00);"-"`（千分位、负数括号、零显示 `-`） |
| 日期格式 | `yyyy"年"mm"月"dd"日"` |
| 百分比格式 | `0.00%` |

## 8. 打印设置

- 横向（landscape）、A4（paperSize=9）。
- `fitToWidth=1`（一页宽）、`fitToHeight=0`（不限页数）。
