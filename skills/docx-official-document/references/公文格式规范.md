# 中文公文格式规范（v1.0）

> 来源：对一份中文培训/课程类文档的实际 OOXML（styles.xml / document.xml / footer）解析整理。
> 适用范围：凡新建 / 编辑 / 输出 / 导出的中文正式 `.docx`（课程/培训材料、公文、证明、报告、方案、通知、函等）。**特殊情况除外。**

### 版本记录
- **v1.0.2**：表格内文字由小三 15pt 调整为小四 12pt（表格观感更轻）
- **v1.0.1**：① 表格内文字与正文同规格 ② 取消标题 5（四级标题）层级 ③ 导航窗格 / TOC 识别要求（标题必须用内置 heading 样式）
- **v1.0**：全文西文/数字一律 Times New Roman；题目、三级标题与正文规范表

## 1. 页面与页码

| 项目 | 规范 |
|---|---|
| 纸张 | A4（11906 × 16838 twips = 21.0 × 29.7 cm） |
| 页边距 | 上/下 2.54 cm（1440 twips）、左/右 3.17 cm（1800 twips） |
| 页眉 / 页脚距离 | 851 / 992 twips |
| 页脚 | **居中阿拉伯数字页码（PAGE 域）**，即 Word「插入 → 页码 → 页面底端 → 居中」 |
| 页眉 | 无内容 |
| 页码规则 | 成稿预计 ≥ 2 页必须加页脚页码（通用约定）；单页可省略 |

## 2. 字体全局规则（硬性）

- **全文所有西文字母、数字、标点符号：一律 `Times New Roman`** —— 每个 run 的 `ascii` / `hAnsi` 均设为 `Times New Roman`（含标题内的西文与数字，不因标题中文字体不同而例外）。
- 中文字体按下方层级表设 `eastAsia`。

## 3. 样式层级表（核心）

| 用途 | Word 样式 | 示例 | 中文字体（eastAsia） | 字号 | 加粗 | 对齐 | 行距 | 段前/段后 | 首行缩进 |
|---|---|---|---|---|---|---|---|---|---|
| **题目** | 标题 1 | 《课程说明》/ 大标题 | 方正小标宋简体 | 二号 22pt | 是 | 居中 | 固定 28.9 磅 | 段后 1 行 | 无 |
| **一级标题** | 标题 2 | 一、二、三、… | 黑体 | 小三 15pt | 是 | 左对齐 | 默认 | 段前/段后各 7.8 磅 | 无 |
| **二级标题** | 标题 3 | （一）（二）… | 楷体 | 小三 15pt | 是 | 左对齐 | 默认 | 无 | 无 |
| **三级标题** | 标题 4 | 1、2、3、… | 仿宋_GB2312 | 小三 15pt | 是 | 左对齐 | 默认 | 无 | 无 |
| **正文** | Normal | 正文段落 | 仿宋_GB2312 | 小三 15pt | 否 | 两端对齐 | 固定 22 磅 | 段前/段后 0 | 首行缩进约 2 字符（600 twips） |

> 原文格式均**只由样式驱动**（标题 1–4 + Normal），无逐段直接改格式，保证输出稳定不漂移。
> 若实现环境没有上述样式定义，应直接按表中"中文字体 + Times New Roman + 字号 + 加粗 + 对齐 + 行距 + 缩进"设置段落/run，效果等同。

## 4. 编号、一致性、导航（硬性）

- 标题编号 **手打**（「一、」「（一）」「1、」），**不用自动列表**（避免自动编号导致格式/编号错乱）。
- 标题保持「与下段同页（keepNext）+ 段中不分页（keepLines）」。
- 正文首行缩进 2 字符；不设悬挂缩进。
- 无特殊要求时不插手动分页符（表格规范见 §5）。
- **导航 / TOC 识别（硬性）**：标题段落必须使用 Word **内置**标题样式 `heading 1` / `heading 2` / `heading 3` / `heading 4`（自带 `outlineLvl` 0–3），禁止用"加粗+大字号"伪标题或自定义样式替代；否则 Word 左侧「导航」窗格与 TOC 字段无法识别/点击跳转。docx-js 用 `HeadingLevel.HEADING_1`~`HEADING_4`（不是数字字符串），python-docx 用 `paragraph.style = doc.styles['Heading 1']`。

## 5. 表格内文字规范

- 表格内所有文字（含表头、数据单元格、说明列）：中文=仿宋_GB2312、西文/数字=Times New Roman、字号=**小四 12pt**（sz=24 半磅）、行距默认（不沿用正文 22 磅，避免过高）。
- 默认不加粗（除非该单元本身就是标题行，如"表头"行可单独加粗 12pt）。
- 表格自身：边框=单线 0.5 磅，列宽按需但总宽 ≤ 页面内容宽（A4 减边距 ≈ 15.04 cm = 8640 twips）。
- 实现示例见 §6。

## 6. 实现要点（python-docx / docx-js）

```python
# 任意 run 的中西文设置（标题与正文通用）
run.font.name = 'Times New Roman'          # ascii/hAnsi = Times New Roman（西文与数字）
rpr = run._element.get_or_add_rPr()
rfonts = rpr.get_or_add_rFonts()
from docx.oxml.ns import qn
rfonts.set(qn('w:eastAsia'), '仿宋_GB2312')  # 按层级：方正小标宋简体/黑体/楷体/仿宋_GB2312
run.font.size = Pt(15)                        # 按层级：22/15/15/15
run.font.bold = True                          # 正文 False

# 正文段落
para.paragraph_format.first_line_indent = Pt(30)   # ≈2字符(15pt×2)
para.paragraph_format.line_spacing = Pt(22)        # 固定值行距
# line_spacing_rule = WD_LINE_SPACING.EXACTLY  （若库需要显式给 rule）

# 导航/TOC 识别：必须用 Word 内置标题样式
para.style = doc.styles['Heading 1']        # 题目
para.style = doc.styles['Heading 2']        # 一级
para.style = doc.styles['Heading 3']        # 二级
para.style = doc.styles['Heading 4']        # 三级
# docx-js: new Paragraph({ heading: HeadingLevel.HEADING_1, ... }) 等
```

```javascript
// docx-js 表格内文字：与正文同规格
import { Table, TableRow, TableCell, Paragraph, TextRun, WidthType } from 'docx';
const body15 = { font: { name: 'Times New Roman', eastAsia: '仿宋_GB2312' }, size: 22 /* half-points=15pt */ };
new Table({
  width: { size: 8640, type: WidthType.DXA },
  columnWidths: [2880, 5760],                 // 示例：两列 4cm + 8cm
  rows: [
    new TableRow({
      children: [
        new TableCell({ width: { size: 2880, type: WidthType.DXA },
          children: [ new Paragraph({ children: [ new TextRun({ text: '表头A', ...body15, bold: true }) ] }) ] }),
        new TableCell({ width: { size: 5760, type: WidthType.DXA },
          children: [ new Paragraph({ children: [ new TextRun({ text: '表头B', ...body15, bold: true }) ] }) ] }),
      ]
    })
  ]
});
```

## 7. 与此前「公文证明类」的关系

同一套强制规范亦覆盖工作经历证明 / 结案报告 / 法律意见书 / 通知函等中文正式文书；除非另有指定，不再另设格式，避免输出样式多变。
