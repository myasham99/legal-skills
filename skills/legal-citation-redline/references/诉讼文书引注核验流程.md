# 诉讼文书引注核验流程（用户强制约定 · 2026-09-11）

适用于答辩状、起诉状、质证意见、代理词等**诉讼文书**的法条／司法解释／判例引注核验。
与法学论文脚注（本 skill 主体功能）不同：诉讼文书**不用脚注**，核验结果以「引注核验表 + 文书批注」两件套呈现。

## 一、三步流程

1. **取原文**：用 `npc-law-db` 逐条取官方条文原文（`scripts/article.py {条号} {法律名或bbbs}`），判例另核裁判文书／法院公开信息。**不得凭记忆写条号。**
2. **出核验表**：生成《引注核验表》，格式见下。
3. **回注文书**：在文书（答辩状等）中，用**同一序号**把核验结果写成 Word 批注，锚定在该引注第一次出现处。

## 二、《引注核验表》格式（用户确认版）

- **标题**：`××状引注核验表`（如「答辩状引注核验表」），标题 1，居中，**黑色**。
- **表头信息（逐行，不合并、不加粗）**：

```
文书：《答辩状【相对方】项目简称案号》
案号：（20XX）Xxxxx民初XXXX号
受诉法院：佛山市南海区人民法院
案由：请求撤销个别清偿行为纠纷
核验日期：2026年9月10日
核验方式：法条/司法解释逐条与国家法律法规数据库（flk.npc.gov.cn）官方原文比对；判例核对裁判文书与法院公开信息。
```

- **核验表格**（`Table Grid`，4 列）：`序号 | 答辩状引注 | 类型 | 核验来源与结论`
  - 列宽 500 / 2500 / 1300 / 4340（表宽 8640）；表头居中，数据行序号列居中、其余左对齐；单元格文字小四 12pt。
  - 「类型」写：法律（原文比对）／司法解释（原文比对）／判例（裁判要旨）／权威观点（非判例）／在案文书（形式核对）。
  - 「核验来源与结论」给出**条文原文**（或判例要旨）＋核验来源＋一句结论（一致／建议复核）。
- **结尾不再写**「核验结论」「核验说明」「复核依据」「复核限制」等段落——**只保留表头信息 + 核验表格**（用户明确要求）。
- 全文**只用黑色**，不设彩色。

## 三、序号 ↔ 文书批注的联动（用户确认版）

- 核验表的**行号即序号**（1、2、3…），在文书中引用同一序号。
- 在诉讼文书的**批注**里按下列格式写明，序号与核验表完全一致：

```
【引注核验 #7】《民事诉讼法》第67条第1款原文：“当事人对自己提出的主张，有责任提供证据。”
核验来源：国家法律法规数据库（flk.npc.gov.cn）；结论：一致。
（可按需补：庭审要点、待补证据、风险提示）
```

- 批注锚点：锚定该引注在文书中**第一次出现的文本**（点锚即可）。
- 批注作者统一写 **`reviewer`**。
- 判例类批注写：`【引注核验 #10】案名，法院（年份）字号民事判决书／裁定书。裁判要旨：……核验来源：……；结论：……`

## 四、批注的完整用法（用户确认版）

用户要求批注**不限于标题**，应尽量多写，把工作细节放入批注、正文从简：

| 批注位置 | 内容 |
|---|---|
| 一级标题 | 该段属**程序抗辩**还是**实体抗辩**（**不要写进标题文字**，标题保持干净） |
| 每条引注处 | `【引注核验 #N】`＋法条原文＋核验来源＋结论 |
| 答辩请求／事实与理由 | 庭审答辩要点（抗辩顺序、举证责任分配、对方可能的反驳与应对） |
| 事实与理由 | 待收集／待补证据清单（逐项写明证明目的） |
| 此致／落款处 | 提交提示（副本份数、期限、是否需补充答辩／质证意见、开庭时间核实） |
| 其他 | 法律规定的原由、风险提示、需向承办律师确认的事项等 |

## 五、质量红线

- **引号内的原文引用不得改写**：条号在引文中按原文（条、款用汉字，项用汉字加括号）。行文援引则用阿拉伯数字并省略括号（《法学引注手册》2019年版规则61）。
- 司法解释按规则 64 标文件号（如 法释〔2020〕18号）；按规则 59 在首次出现处说明简称。
- 判例按规则 70／71 写案例名称＋审判法院全名＋（年份）案号＋文书类型。
- 找不到原文时标 `[待补: 条文原文]`，**不得杜撰**。
