# 项目编码对照表（结构与用法）

> 用途：把「项目编码 → 项目名称 / 分类 / 开工日期」的对照关系落成可查表，供台账填报与字段映射使用。
> **本仓库不含真实项目清单**——请导出本单位的项目编码台账（xlsx），按下表结构替换示例行。

## 字段说明

| 字段 | 含义 |
| --- | --- |
| `code600` | 工程项目编码（600 开头主编码，通常用于对上报表） |
| `code12` | 原工程项目编码（12 开头旧编码，常见于借款 / 履约类台账） |
| `name` | 工程项目名称 |
| `cat` | 项目分类（用于「涉案项目性质」映射，见下） |
| `start` | 实际开工日期 |
| `unit` | 所属三级单位 |

检索方式：按项目简称 / 名称模糊匹配；按 `code12` 精确匹配取 `code600`；按 `code600` 反查名称 / 分类 / 开工日期。

## 项目分类 → 涉案项目性质 映射参考

| 项目分类 | 涉案项目性质 |
| --- | --- |
| 基础设施建设项目（市政道路、公路、桥梁、隧道、水务、风电、污水处理、管廊等） | 基础设施 |
| 房屋建设项目 / 工业加工厂房、工业制造厂房 | 工业厂房 |
| 房屋建设项目 / 教育设施（学校） | 基础设施 |
| 房屋建设项目 / 其他（住宅、保障房、写字楼、酒店、医疗等） | 房建 |

> 具体归类以本单位报表口径为准；存在项目被特别指定的情形时，以特别指定为准。
