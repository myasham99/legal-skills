# 项目简称映射表（结构与用法）

> 用途：把「项目编码 → 项目全称 → 项目简称 → 利润中心」的对照关系落成可查表，供文件命名、台账填报时在简称与全称之间互转。
> **本仓库不含真实项目清单**——请按本单位项目台账替换示例行。

## 字段说明

| 字段 | 含义 |
| --- | --- |
| `code` | 项目编码（内部旧编码，常见为 12 开头） |
| `full` | 项目全称（与合同 / 台账保持一致） |
| `short` | 项目简称（用于文件命名、日常沟通） |
| `profit_center` | 利润中心编码（可留空） |

要点：
- 同一项目编码可能对应多个简称（同一项目的不同习惯叫法）；同一简称也可能对应多个项目。程序按 `code + short` 组合处理。
- 若项目名称存在历史变更，建议保留新旧两条并在备注中说明。
